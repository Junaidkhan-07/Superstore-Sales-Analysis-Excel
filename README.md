# Superstore Sales Analysis & Excel Dashboard

## 📊 Project Overview

This project analyzes Superstore sales data using **Microsoft Excel** to identify sales performance, profitability, customer segments, regional trends, and product performance.

The project follows a complete data analytics workflow — from **data cleaning and validation to analysis, visualization, and dashboard development**.

## 🎯 Business Problem

The objective of this project is to transform raw sales data into meaningful business insights and answer questions such as:

* What is the overall sales performance?
* Which categories and regions generate the most sales?
* Which products perform best?
* How do different customer segments contribute to sales?
* What are the key sales and profit trends?
* Which areas may require further business attention?
